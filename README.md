TrustRent

A full-stack rental platform that builds trust between tenants and landlords through rental history, payment behavior, reviews, and trust scores.

Tech Stack
Frontend: React
Backend: Spring Boot, Java
Database: PostgreSQL
Authentication: JWT
APIs: REST
Key Features
User authentication and role-based access
Property listing and management
Rental applications
Monthly rent and payment tracking
Tenant/landlord reviews
Dynamic trust score based on rental behavior
Project Structure
TrustRent/
├── frontend/   # React application
└── backend/    # Spring Boot REST API
Run Locally
# Backend
cd backend
mvn spring-boot:run

# Frontend
cd frontend
npm install
npm run dev

A platform focused on making the rental process more transparent, reliable, and trust-driven.
